# Front-End Documentation

The front end uses semantic HTML5, one external CSS file, and one external JavaScript file.

- `assets/css/styles.css`: responsive layout, cards, forms, tables, menus, transitions, accessibility, and three CSS-variable themes.
- `assets/js/app.js`: mobile navigation, live custom quote calculator, and canvas chart.
- `includes/header.php` and `includes/footer.php`: shared site-wide layout.
- Product and admin pages are rendered dynamically from MySQL.
- Breakpoints at 850px and 560px support desktop and mobile layouts.
