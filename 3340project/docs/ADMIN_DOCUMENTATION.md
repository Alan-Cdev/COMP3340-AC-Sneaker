# Admin Documentation

## Administrator Login

Go to:

https://chen5w.myweb.cs.uwindsor.ca/3340project/login.php

Login using an administrator account.

---

## Admin Features

The administrator can:

- Manage products
- Edit product information
- Manage customer accounts
- Disable or enable users
- View orders
- Switch between the three available themes
- Monitor website status

---

## Theme Switching

Navigate to the Theme section and select:

- Light
- Midnight
- Sunset

The selected theme will be applied across the website.

---

## Product Management

Products can be edited directly through the Admin Dashboard.

Changes are immediately reflected on the customer pages.

---

## User Management

Administrators can:

- Activate users
- Disable users
- View registered accounts
