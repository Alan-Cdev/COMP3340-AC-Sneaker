# AC Sneaker PHP/MySQL Project

AC Sneaker is a full-stack sneaker catalogue and ordering website created for a university web-development project.

## Main features
- 20 database-driven products with multiple colors and sizes
- Customer registration, login, profile, cart, checkout, order history, and service requests
- Admin product editing, user disabling, support responses, theme switching, and monitoring
- Three site-wide templates: Modern, Midnight, and Sunset
- Responsive menu and layouts
- Search, filters, quote calculator, map, multimedia, and canvas data visualization
- Six-page help wiki
- SEO metadata and favicon
